# MASARAK — Interactive Prototype

The interactive MASARAK prototype is available in Figma.

[Open MASARAK Prototype](https://www.figma.com/design/pECJ0o9O7KBDzS2KUgmK5g/MASARAK-%E2%80%94-Android-Prototype?node-id=2-105743&t=668XoZqkUO5OuHUJ-1)

## How to Use

1. Open the prototype link.
2. Choose the user flow you want to explore:
   - Student
   - Field Supervisor
   - Academic Supervisor
3. Start from the selected role’s SplashScreen.
4. Follow the buttons and navigation normally.

Best viewed using the Android Compact device preset in Figma.
