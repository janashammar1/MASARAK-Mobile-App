# MASARAK — Screens and Navigation

This folder contains the finalized MASARAK screens and navigation flows for all user roles.

## Included Files

- Student Screens and Navigation
- Field Supervisor Screens and Navigation
- Academic Supervisor Screens and Navigation
- Supporting Screens

The navigation documentation shows the main screen-to-screen flow for each role, including the primary path, branches, returns, and supporting UI states.

## User Roles

- Student
- Field Supervisor
- Academic Supervisor

## Important: PDF Preview on GitHub

Some screen and navigation PDF files are large, so GitHub may display the message:

**“Unable to render code block”**

This does not mean the PDF file is missing or corrupted.

If this message appears:

1. Open the PDF file in GitHub.
2. Click **Download** or **View raw / Raw**.
3. Open the downloaded PDF normally on your device.

All PDF files in this folder are complete and included in the repository.
